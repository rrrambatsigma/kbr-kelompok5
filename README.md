# KBR - Plant Disease Expert System

## Tujuan
Mengembangkan knowledge base dan expert system
untuk mendukung diagnosis awal penyakit tanaman pangan tropis.

## Tahapan
1. Knowledge Acquisition
2. Knowledge Representation
3. Knowledge Base Development
4. Reasoning Implementation
5. Validation
6. Backend Development
7. Frontend Development
8. Evaluation
